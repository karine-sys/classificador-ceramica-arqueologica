# 🏺 Classificador de Cerâmica Arqueológica com Machine Learning

Projeto em Python criado para classificar fragmentos cerâmicos (culturas Marajoara e Santarém) a partir de atributos físicos e químicos como espessura e teor de ferro.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Manipulação de Dados:** Pandas
- **Machine Learning:** Scikit-Learn (Decision Tree Classifier)
